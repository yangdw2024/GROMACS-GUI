# 科研计算可靠性与物理模型验证基线
## Scientific Validation & Physical Consistency

## 一、软件科学验证范围与证据边界

GROMACS-GUI 作为分子动力学模拟图形化调度与流程管理桌面软件，其科学可靠性基线**仅建立在软件工程逻辑、文件输入输出完整性校验及确定性测试用例**的基础之上：

- **软件负责的边界**：
  1. GROMACS 命令行参数的精确拼装与透传；
  2. 模拟阶段间输入/输出结构与拓扑文件链条的继承完整性；
  3. 检查点文件 (`.cpt`) 的同轮中断安全恢复与跨轮原子数变化严格隔离；
  4. 溶剂/分子删除算法中的原子行格式、分子完整性与拓扑分子数同步扣减；
  5. 运行后置结构与日志中的数值发散 (`NaN` / `Inf`)、物理塌陷与约束崩溃探测。
- **科研结论与参数的边界**：
  - 仓库内 `examples/` 目录下的输入文件与脚本属于独立的局部功能演示案例，来自不同的体系配置，**不属于同一套正式研究体系，亦未构成统一的标准生产协议**；
  - 具体科研研究体系的物理模型选择（力场、电荷模型、控温控压算法、成膜/退火工艺及弛豫时间尺度）属于科研人员独立学术判断范畴，本工程文档不推断亦不证明任何具体实验体系的模拟结论。

## 二、SA 溶剂蒸发逐轮结构继承法则

在溶剂分批删除与阶段循环平衡模拟中，软件通过 `source/simulation/md_runner.py` 与 `source/gui/embedded_scripts.py` 严格执行以下物理继承约束：

### 1. 结构与动力学量继承
- **第 $i$ 轮输入结构**：必须严格等于第 $i-1$ 轮成功完成的 `mdrun` 输出结构 `${PREFIX}_${i-1}.gro`（第 1 轮使用初始输入结构）；
- **微观盒子与速度继承**：
  - 原子坐标与微观收缩盒子矢量从上轮输出结构继承传递；
  - 速度信息从输入 `.gro` 结构中读取（对应 MDP 中 `continuation = yes` 与 `gen_vel = no`），避免每轮重新生成破坏已弛豫的速度分布。

### 2. Checkpoint 跨轮隔离与同轮恢复规则
- **严禁跨轮复用旧 `.cpt`**：因删除溶剂导致系统总原子数发生物理变化，将上一轮旧 `.cpt` 文件用于新一轮启动会导致 GROMACS 抛出原子数不匹配致命错误，软件调度器严格禁止跨轮 `-cpi` 传递；
- **同轮中断安全续跑**：仅在第 $N$ 轮运行中途中断且当前轮原子数未变时，允许使用本轮生成的 `${PREFIX}_N.cpt` 配合 `-append` 继续未完成的模拟时间步。

## 三、已落地的科学可靠性加固机制

### 1. `grompp -maxwarn` 告警安全上限策略
- 标准 MD 各步骤默认 `-maxwarn 2`；
- SA 蒸发与退火步骤收敛至 `SA_SAFE_MAXWARN = 5`，代码底层设立 `MAXWARN_HARD_CAP = 10` 硬门禁（`validate_maxwarn`），严禁使用 `-maxwarn 200` 等盲目放行参数，防止掩盖真实力场拓扑错误或参数缺失。

### 2. 溶剂删除算法的正确性与模式区分
- **旧版 GRO 记录顺序模式 (`bottom` / `top`)**：
  - `bottom` 模式从 GRO 文件末尾向前匹配完整分子块；`top` 模式从 GRO 文件开头向后匹配；
  - 100% 保留以确保历史已有脚本和流程重现性。
- **空间几何中心 Z 轴排序模式 (`z_top` / `z_bottom`)**：
  - 计算每个候选分子的几何中心 $Z$ 坐标，优先删除物理空间上处于最顶层或最底层的分子，解决文件记录顺序与空间位置不一致的问题。
- **拓扑同步一致性**：删除分子后强制核验 `[ molecules ]` 节中的分子数扣减，禁止产生负数或孤立原子。

### 3. 运行后置物理一致性自检 (`source/simulation/validation.py`)
- **结构校验 (`validate_gro_structure`)**：
  - 校验 GRO 实际原子行数与声明原子数完全一致；
  - 扫描所有原子坐标，拦截 `NaN`、`Inf` 等数值发散；
  - 校验末行三维盒子矢量正定性，拦截坍塌为 0 的异常盒子。
- **日志自检 (`validate_md_log`)**：
  - 拦截 `Fatal error`、`Segmentation fault`、`Too many LINCS warnings` 与水分子 SETTLE 崩溃；
  - **凝聚相 NPT 瞬时压力波动豁免**：凝聚相盒子因压缩率极低，压力瞬时值在 $\pm 500 \sim 2000\text{ bar}$ 间剧烈震荡属物理正态分布，后置检查仅在出现非有限数值 (`NaN`/`Inf`) 或致命报错时阻断，不将瞬时压力负值误报为计算失败。

### 4. MMPBSA 参数换算与适用边界
- **时间帧索引严格换算**：GUI 输入的物理时间 (ps) 必须依据真实轨迹输出步长 (`traj_dt_ps`) 换算为 1-based 帧号 (`startframe`, `endframe`, `interval`)，严禁直接将 ps 数值作为帧号传递；
- **NDX 索引组动态读取**：通过 `parse_ndx_groups` 解析实际索引文件，由用户指定 `-cg` 受体与配体组别，废除硬编码组别；
- **适用边界声明**：针对非标准复合物体系的隐式溶剂结合自由能计算属于实验性辅助工具，科研适用性须由用户依据研究对象独立评估。
