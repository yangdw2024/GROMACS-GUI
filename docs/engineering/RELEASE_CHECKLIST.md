# 正式版本发布检查清单与准出准则
## Release Checklist & Production Quality Gates

本清单定义了 GROMACS-GUI 发布正式稳定版本的最终准入与准出门禁。只有以下全部条款通过客观证据验证，方可创建 Release 并合并 master。

---

## 一、发布准出门禁（Quality Gates）

- [ ] **Gate 1: 代码与依赖审查 (L1)**
  - 源码无调试遗留、无未处理 TODO/FIXME 阻断项；
  - 全部 Python 文件通过 `py_compile` 语法编译；
  - 依赖清单（`requirements.txt` / 打包依赖）版本锁定且无版本冲突。
- [ ] **Gate 2: 自动化测试全绿 (L2)**
  - 本地与 GitHub Actions 跨 Python 3.11 & 3.12 测试通过率 100%；
  - 无跳过核心计算测试，无挂起、超时或 Cancelled 现象。
- [ ] **Gate 3: GUI 核心交互与生命周期 (L3)**
  - 七大功能页面（结构建模、基础MD、进阶模拟、轨迹处理、结果分析、MMPBSA、自定义脚本）组件化装配完整；
  - 任务启动、运行锁定、停止响应与错误日志输出自洽，无悬挂进程/线程；
  - 经典双栏布局与现代工作台视图平滑往返切换正常。
- [ ] **Gate 4: 科研计算可靠性闭环 (L4)**
  - SA 溶剂蒸发逐轮 NPT 继承、CPT 同轮恢复、GRO/TOP 分子数守恒通过客观验证；
  - 未修改任何历史科研模拟数据与正式物理参数。
- [ ] **Gate 5: 视觉体验与高 DPI 适应性 (L5)**
  - 深色与浅色双主题无色差污染，文字对比度合格；
  - 880×620、1024×768、1280×820、1920×1080 及 100%、150%、200% DPI 下无截断、无重叠、无溢出；
  - 真实运行截图经审查存档。
- [ ] **Gate 6: 文档与国际化 (L6)**
  - 中英文双语界面切换无错位，无硬编码中文业务分支；
  - README (zh/en)、用户操作手册、架构设计文档、Changelog 齐全。
- [ ] **Gate 7: 生产安装包与环境验证 (L7)**
  - Windows 原生构建（PyInstaller + Inno Setup）生成正式 `.exe` 安装包与便携包；
  - 在干净 Windows 虚拟机/物理机上完成安装、快捷方式生成、启动与卸载测试。
- [ ] **Gate 8: 安全与合规交付 (L8)**
  - 绝对不包含用户私人科研模拟轨迹数据、PDB、密钥、Token 或内部密码；
  - 开源许可证（LICENSE）与应用内部协议一致；
  - 提供发布产物的 SHA256 校验和。
