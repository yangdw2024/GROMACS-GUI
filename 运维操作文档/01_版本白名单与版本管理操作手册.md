# 版本管理操作手册

## 一、版本显示机制

### 1.1 版本显示规则
系统默认**显示所有已安装的GROMACS版本**，不再进行去重过滤。每个版本都会出现在下拉列表中，用户可以自由选择。

### 1.2 版本有效性检测
系统会自动检测每个版本的完整性，标记为"有效"或"无效"：

| 检测项 | 说明 |
|--------|------|
| gmx.exe | 核心可执行文件是否存在 |
| 力场目录 | `share/gromacs/top/*.ff` 是否完整 |
| CUDA DLL | `cudart64_*.dll`、`cufft64_*.dll` 等是否存在 |
| PLUMED DLL | 若版本名称含PLUMED，检查`libplumedKernel.dll` |

无效版本会显示在列表中但会有警告标记，建议不要使用。

## 二、版本批量导入/导出功能

### 2.1 打开版本管理对话框
点击【版本管理】按钮，打开版本导入导出对话框。

### 2.2 批量导出版本

#### 操作步骤
1. 在版本列表中勾选要导出的版本（支持多选）
2. 点击【全选】可一键勾选全部版本
3. 点击【清空勾选】取消所有勾选
4. 点击【导出勾选版本】
5. 选择导出目录
6. 等待导出完成

#### 导出特点
- 自动过滤临时编译垃圾文件（CMakeCache、.pyc、__pycache__等）
- 仅打包完整GROMACS版本目录
- 每个版本生成独立的ZIP压缩包

### 2.3 批量导入版本

#### 操作步骤
1. 点击【导入版本】
2. 选择外部的GROMACS版本ZIP压缩包（支持多选）
3. 等待导入完成

#### 导入校验
- 自动检查压缩包是否包含`gmx.exe`
- 自动校验版本有效性（力场目录、CUDA依赖等）
- 冲突版本弹窗提示，不会覆盖已有版本

## 三、版本完整性检测

### 3.1 检测项说明
系统自动检测每个版本的完整性：

| 检测项 | 说明 |
|--------|------|
| gmx.exe | 核心可执行文件是否存在且非空 |
| 力场目录 | `share/gromacs/top/*.ff` 是否完整 |
| CUDA DLL | `cudart64_*.dll`、`cufft64_*.dll`、`cublas64_*.dll` 等是否存在 |
| PLUMED DLL | 若版本名称含PLUMED，检查`libplumedKernel.dll` |

### 3.2 版本状态标记
- **有效**：所有检测项通过
- **无效**：至少一项检测失败，建议修复或删除

## 四、常见问题解答

### Q1：如何备份我的GROMACS版本？
**A**：使用版本管理对话框的导出功能，选择版本后导出为ZIP压缩包。

### Q2：导入的版本显示"无效"怎么办？
**A**：检查压缩包完整性，确保包含完整的`bin/`和`share/`目录，以及CUDA依赖DLL。

### Q3：为什么我的版本显示无效？
**A**：常见原因包括：缺少CUDA运行时DLL（cudart64_*.dll）、力场目录不完整、PLUMED版本缺少libplumedKernel.dll。
