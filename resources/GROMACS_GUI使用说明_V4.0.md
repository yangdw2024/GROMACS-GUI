## 程序概述

本程序是基于 PyQt5 开发的 GROMACS 图形化界面工具，旨在为分子动力学模拟提供一站式的可视化操作平台。

### 主要功能
- ✅ 完整的分子动力学模拟流程 (pdb2gmx → editconf → solvate → genion → EM → NVT → NPT → MD)
- ✅ 溶剂/添加剂蒸发模块 (支持循环删除 + NPT 平衡)
- ✅ 退火模拟模块
- ✅ 高级模拟方法 (伞形采样、元动力学、ABF)
- ✅ 20+ 种结果分析工具
- ✅ 轨迹处理工具
- ✅ 结构处理与索引生成
- ✅ MMPBSA 结合自由能计算
- ✅ 自定义脚本 (PowerShell / Batch / Shell)
- ✅ GPU 加速支持
- ✅ 断点续跑支持
- ✅ Windows Job Object 内存限制
- ✅ 实时监控面板
- ✅ 配置保存与加载

### 系统要求
- Windows 10/11 操作系统
- 已安装 GROMACS (建议 2020.6 或更高版本)
- 建议配备 NVIDIA GPU 以获得更好的性能

## 7个功能模块详解

### Part 1: MD模拟 (核心功能)

最常用的核心模块，包含完整的 12 步分子动力学模拟流程，分为 4 个阶段：

#### 第一阶段: 结构准备 (Step 1-4)
- **Step 1**: 生成拓扑 (pdb2gmx)
  - 支持"使用已有拓扑"选项，跳过 pdb2gmx，直接使用现有 GRO/PDB 和 TOP 文件
- **Step 2**: 定义模拟盒子 (editconf)
  - 支持 5 种盒子类型：立方体、长方体、十二面体、八面体、三斜
  - 两种设置方式：按边距 (-d) / 按盒子边长 (-box)
  - 支持三斜盒子角度设置 (α/β/γ)
- **Step 3**: 溶剂化 (solvate)
- **Step 4**: 添加离子 (genion)

#### 第二阶段: 能量最小化 (Step 5-6)
- **Step 5**: grompp (EM)
- **Step 6**: mdrun EM - 执行能量最小化
  - EM 使用 steep 积分器，不支持 GPU PME 和 GPU update
  - 自动使用 `-nb gpu -pme cpu -bonded gpu -update cpu`

#### 第三阶段: 平衡模拟 (Step 7-10)
- **Step 7**: grompp (NVT)
- **Step 8**: mdrun NVT - 恒温恒容平衡
- **Step 9**: grompp (NPT)
- **Step 10**: mdrun NPT - 恒温恒压平衡

#### 第四阶段: 生产模拟 (Step 11-12)
- **Step 11**: grompp (MD)
- **Step 12**: mdrun MD - 生产模拟

**断点续跑**: Step 6/8/10/12 均支持勾选"断点续跑"。若检测到 `{deffnm}.cpt` 检查点文件，会自动添加 `-cpi -append` 参数继续模拟。

**自定义输出前缀**: Step 6/8/10/12 支持勾选"自定义输出前缀"，可手动指定 deffnm，否则默认使用输入 TPR 文件名前缀。

---

### Part 1 子模块: 溶剂/添加剂蒸发

用于模拟溶剂蒸发过程（如 OPV 材料制备中的氯仿挥发）。

#### 工作模式
- **分批蒸发溶剂**: 循环执行"删除指定数量溶剂分子 → grompp → mdrun"
  - 溶剂残基名 (如 CF)
  - 每轮删除数量
  - 循环轮数
  - 每分子原子数
- **一次性删除添加剂**: 删除指定残基的所有分子，然后跑 NPT

#### 文件管理模式
采用 original/work/current 模式，避免冗余文件：
- `{prefix}_original.gro/top`: 备份原始输入文件
- `{prefix}_work.gro/top`: 当前工作文件
- `{prefix}_current.gro/top`: 最新已完成的结果
- `{prefix}_{i}.gro/tpr/log/edr/xtc/cpt`: 每轮 mdrun 输出

#### 断点续跑
勾选"断点续跑"并设置起始轮数后，程序会自动寻找上一轮结果继续执行。

---

### Part 1 子模块: 退火模拟

用于模拟退火过程（Annealing）。

1. 输入 GRO 和 TOP 文件
2. 在表格中定义退火曲线（时间-温度点对）
3. 选择退火模式：single（单次）或 periodic（周期性）
4. 程序自动生成 `{prefix}.mdp` 并执行 grompp + mdrun

---

### Part 2: 结构处理

结构处理是模拟前的准备步骤：

1. **创建索引文件 (gmx make_ndx)**
   - 快捷选择：蛋白质、配体、水、离子、主链、侧链
   - 自定义选择：支持任意 GROMACS 选择语法
   - 输出文件：index.ndx

2. **编辑结构 (editconf)**
   - 修改盒子参数、旋转、平移、居中对齐
   - 支持多种盒子类型

3. **生成拓扑 (pdb2gmx)**
   - 从 PDB 结构生成 GROMACS 拓扑文件
   - 支持多种力场选择

4. **生成位置限制 (genrestr)**
   - 生成位置限制文件 (posre.itp)

5. **生成构象 (genconf)**
   - 生成多个结构副本或旋转构象

6. **结构分析工具**: RMSD、RMSF、SASA、氢键、RDF、最小距离等

---

### Part 3: 高级模拟

#### 伞形采样 (Umbrella Sampling)
- 用于计算自由能剖面
- 支持 PLUMED 或 GROMACS 内置 pull 代码
- 生成 MDP 文件和 PLUMED 文件

#### WHAM 分析
- 加权直方图分析方法
- 处理伞形采样结果

#### 元动力学 (Metadynamics)
- 增强采样方法
- 基于 PLUMED 实现

#### ABF (Adaptive Bias Force)
- 自适应偏置力方法
- 计算自由能

---

### Part 4: 轨迹处理

| 工具 | 功能 | 常用选项 |
|------|------|----------|
| trjconv | 轨迹转换 | -pbc mol -center -fit rot+trans |
| trjcat | 轨迹合并 | 合并多个轨迹文件 |
| trjorder | 轨迹排序 | 按指定顺序重排原子 |
| trjreshape | 轨迹重塑 | 改变帧数或时间步 |
| trjreduce | 轨迹精简 | 减少轨迹帧数 |
| trjcluster | 轨迹聚类 | 对构象进行聚类 |
| trjstrip | 轨迹剥离 | 移除溶剂等原子 |

---

### Part 5: 结果分析

分为 4 大类，共 19 种分析工具：

#### 能量与热力学分析
- 能量分析 (温度、压力、密度、能量等)
- 密度分析
- 均方位移 (扩散系数)

#### 结构稳定性分析
- RMSD、RMSF、回旋半径、距离、角度、配对距离分布

#### 相互作用分析
- 氢键、RDF、SASA、盐桥、二级结构 (DSSP)

#### 高级分析方法
- 协方差矩阵、特征值分解、PCA、轨迹投影、聚类分析

**参数设置**:
- 计算开始/结束时间
- 采样时间间隔

## 快速入门指南

### 场景一：标准蛋白质 MD 模拟

1. **准备结构**
   - 打开 Part 1 → MD模拟
   - 输入 PDB 文件
   - (可选) 切换到 Part 2 创建索引文件

2. **设置参数**
   - 选择力场和水模型
   - 设置盒子类型和大小
   - 设置温度、压力、步数

3. **运行模拟**
   - 依次点击各步骤的"运行"按钮
   - 或点击顶部"一键运行全部"

4. **分析结果**
   - 切换到 Part 4 → 轨迹处理 (去除 PBC)
   - 切换到 Part 5 → 结果分析 (RMSD/RMSF/能量等)

### 场景二：使用已有拓扑

1. 勾选"使用已有拓扑"
2. 选择已有的 GRO/PDB 文件
3. 选择已有的 TOP 文件
4. 点击"确认使用已有拓扑"
5. 跳过 Step 1，直接从 Step 2 开始

### 场景三：溶剂蒸发 (SA) 模拟

1. 切换到 Part 1 → 溶剂/添加剂蒸发
2. 选择输入 GRO 和 TOP 文件
3. 设置 MDP 文件
4. 设置溶剂残基名 (如 CF)、每轮删除数量、循环轮数
5. 点击"运行"

## 高级功能说明

### GPU 加速优化
- 自动检测 NVIDIA GPU
- EM 步骤自动使用 `-nb gpu -pme cpu` (非动力学积分器不支持 GPU PME)
- GPU 加速时 CPU 线程数自动限制为 max(4, min(12, 核心数/2))
- 显式指定 GPU ID 确保正确选择显卡
- 不使用 `-gpu-stream` / `-gpu-staging` 参数，避免 Windows 下 GPU 温度过高

### 内存限制
- 基于 Windows Job Object 实现
- 在"系统配置"中勾选"内存限制"并设置数值
- GROMACS 进程使用的内存将被限制在设定值内
- 超出限制时进程会被系统终止

### 断点续跑
- Step 6/8/10/12 以及溶剂蒸发模块均支持
- 自动检测 `.cpt` 检查点文件
- 自动添加 `-cpi -append` 参数
- 蒸发模块支持从指定轮数继续

### 实时监控面板
- 温度实时曲线
- 压力实时曲线
- 势能/总能量曲线
- 自动调用 gmx energy 提取数据

### 配置保存/加载
- 所有参数保存为 JSON 格式
- 便于项目间切换和复现

### MDP 编辑器
- 可视化编辑 MDP 参数
- 按类别分组显示
- 实时预览生成的 MDP 内容

### 错误诊断
- 自动分析 GROMACS 错误输出
- 给出可能的原因和修复建议

## 常见问题解答

### Q1: 为什么 GPU 加速没有生效？
**A**: 请检查：
1. 是否已安装 NVIDIA 显卡驱动
2. GROMACS 是否编译了 CUDA 支持
3. 是否已在系统配置中勾选"启用GPU"
4. GPU ID 是否正确

### Q2: 运行时闪退怎么办？
**A**: 常见原因：
1. 内存不足 → 调小分子数或减少步数，或启用内存限制
2. GPU 温度过高 → 检查散热
3. 参数设置错误 → 查看日志中的错误信息
4. 使用了不支持的参数 → 参考 GROMACS 手册

### Q3: 如何使用自定义拓扑文件？
**A**: 
1. 在 Part 1 → MD模拟 中勾选"使用已有拓扑"
2. 选择已有的 GRO 和 TOP 文件
3. 点击"确认使用已有拓扑"
4. 跳过 Step 1，直接从 Step 2 开始

### Q4: 盒子类型怎么选？
**A**: 
- **立方体**: 最常用，简单直观
- **十二面体/八面体**: 相同体积下表面积更小，节省溶剂分子
- **三斜**: 最灵活，适合特殊晶格
- **长方体**: 适合膜蛋白等各向异性体系

### Q5: 程序支持哪些 GROMACS 版本？
**A**: 
- 推荐: 2020.6, 2021.x, 2022.x, 2023.x, 2024.x, 2026.x
- 2026.1 不支持 `-noreset` 参数

### Q6: 蒸发模块为什么生成 _original/_work/_current 文件？
**A**: 这是为了减少磁盘冗余：
- `_original` 保存原始输入备份
- `_work` 是当前正在使用的文件
- `_current` 是最近完成一轮后的结果
